# AIO Hub - Your Ultimate Entertainment Center

![AIO Hub](https://img.shields.io/badge/AIO-Hub-purple?style=for-the-badge)
![Status](https://img.shields.io/badge/status-active-success?style=for-the-badge)

A modern, all-in-one entertainment platform that brings music, films, games, and more together in a beautifully designed interface. Built with cutting-edge web technologies and featuring a responsive design with dark/light theme support.

## 🎓 Academic Project

This project was developed as a **PFA (Projet de Fin d'Année)** at **EMSI (École Marocaine des Sciences de l'Ingénieur)**.

- **Authors**: Azzat Nouamane & Aimane Hnid
- **Supervisor**: Mr. Bouchtib Hamza

## 🌟 Features

- **Multi-Platform Entertainment Hub**
  - Music streaming and discovery
  - Film and movie browsing
  - Games collection and showcase
  - Video presentations and demos

- **Modern UI/UX**
  - Stunning gradient-based design
  - Smooth animations and transitions
  - Dark/Light theme toggle
  - Fully responsive layout (mobile-friendly)
  - Glassmorphism effects

- **Interactive Components**
  - AI-powered chatbot assistant
  - User authentication system
  - Profile management
  - Dynamic content loading

- **Technical Features**
  - Video background hero section
  - CSS Grid and Flexbox layouts
  - Custom CSS variables for theming
  - Optimized performance
  - Cross-browser compatibility

## 🚀 Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Custom CSS with CSS Variables, Animate.css
- **Icons**: Font Awesome 6.5.1
- **Fonts**: Google Fonts (Inter, Outfit, Plus Jakarta Sans)
- **Deployment**: Netlify
